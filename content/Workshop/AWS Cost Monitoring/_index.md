#### Workshop overview
This initial workshop shows how users access a cost dashboard through a secure AWS flow.

The end-to-end path is:

1. User opens the workshop access point.
2. User is redirected to an **Amazon QuickSight** dashboard.
3. QuickSight reads billing data from **AWS Cost Explorer**.
4. User sees cost charts and spending trends.
