This workshop introduces a practical cost-monitoring setup for AWS workloads.

The focus is on a user-facing flow where users can open a dashboard and review AWS cost insights.

#### Prerequisites
- AWS account access with permission to use QuickSight and Cost Explorer.
- Sample billing data available in Cost Explorer.
- Browser access to the workshop and dashboard pages.


#### Architecture: 
![overview](/images/2.2-MonitorCost/diagram.png)

#### Key services
- **Amazon QuickSight**: render interactive dashboard charts.
- **AWS Cost Explorer**: provide the cost and usage data source.
