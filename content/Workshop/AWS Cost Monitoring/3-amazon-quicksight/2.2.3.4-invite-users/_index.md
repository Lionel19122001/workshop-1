Invite users to view the QuickSight dashboard.

#### Steps
1. Open the AWS management account that owns the QuickSight dashboard.
![overview](/images/2.2-MonitorCost/33-inviteUser.png)
2. Go to **Manage users**.
![overview](/images/2.2-MonitorCost/34-inviteUser.png)
3. Select **Invite users**.
![overview](/images/2.2-MonitorCost/35-inviteUser.png)
4. Enter the user email address and send the invitation.
![overview](/images/2.2-MonitorCost/36-inviteUser.png)
5. Choose the appropriate role and permissions, then send the invite.
![overview](/images/2.2-MonitorCost/37-inviteUser.png)
6. Open the invitation email and click **Accept invitation**.
![overview](/images/2.2-MonitorCost/38-inviteUser.png)
7. Create the new user profile.
![overview](/images/2.2-MonitorCost/39-inviteUser.png)
![overview](/images/2.2-MonitorCost/40-inviteUser.png)
8. Open the **My Cost** dashboard from the dashboard list.
![overview](/images/2.2-MonitorCost/41-inviteUser.png)

#### Result
The invited user can now access the QuickSight dashboard and export the data they need.
![overview](/images/2.2-MonitorCost/42-inviteUser.png)
![overview](/images/2.2-MonitorCost/43-inviteUser.png)
