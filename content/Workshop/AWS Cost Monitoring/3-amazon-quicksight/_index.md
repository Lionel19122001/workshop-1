This section sets up the cost dashboard in **Amazon QuickSight**.


#### Steps
1. Open **Amazon QuickSight** and create a workshop folder for dashboards.
2. Connect **AWS Cost Explorer** (or your prepared cost dataset) as the data source.
3. Build visuals for monthly trend, top services, and cost by account/project.
4. Publish the analysis as a dashboard and configure viewer permissions.
5. Save dashboard URL details for integration with the sign-in flow.

#### Outcome
You have a published cost dashboard in QuickSight, ready to be connected to your authentication and domain flow.
